# Giuseppe Ruggiero — Cybersecurity & Computer Engineering Portfolio

Static portfolio website hosted on **GitHub Pages** at **[giusepperuggiero-sec.github.io](https://giusepperuggiero-sec.github.io)**, presenting interactive architecture case studies, technical stack filtering, and bilingual **EN / IT** navigation linked directly from my CV and GitHub repositories.

## Features
- **Deep-Linked Case Studies (`#enterprise-iot`, `#ot-ics-tinyml`, `#iomt-xai`):** Dedicated technical breakdowns with expandable interactive **SVG architecture schematics** and verified evaluation metrics.
- **Bilingual Support (`EN / IT`):** Instant client-side language switching (with `?lang=it` query support and `localStorage` persistence) without duplicating HTML markup.
- **Filterable Technical Toolbox:** Interactive category filtering across Blue Team / SIEM, AppSec / Offensive / Malware, Systems / Embedded, Languages, and AI / Data tools.
- **Zero Build Dependencies:** Pure semantic HTML5, modern CSS Grid/Flexbox, and vanilla JavaScript with `.nojekyll` enabled for direct GitHub Pages delivery.

- [`enterprise-iot-red-blue-siem`](https://github.com/giusepperuggiero-sec/enterprise-iot-red-blue-siem) — SME IoT Red & Blue Team kill-chain simulation and Wazuh SIEM correlation lab
- [`ot-ics-tinyml-ai-soc`](https://github.com/giusepperuggiero-sec/ot-ics-tinyml-ai-soc) — 4-shield TinyML Cortex-M7 OT/ICS gateway and local MITRE-grounded AI SOC
